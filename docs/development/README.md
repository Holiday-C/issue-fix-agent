# Development Guides

This directory is the canonical home for day-to-day engineering procedures. Put
repeatable contributor guidance here, such as Git workflows, testing practices,
release steps, and local debugging instructions.

Use the other documentation areas for different kinds of information:

- `docs/architecture.md` defines module boundaries and runtime flow.
- `docs/decisions/` records significant architectural decisions and their
  rationale.
- `README.md` explains product scope and how to get started.
- `CONTRIBUTING.md` is the short entry point for human contributors.
- `AGENTS.md` contains mandatory agent instructions and points to these guides
  when a task needs them.

## Guides

- [`git-workflow.md`](./git-workflow.md): branches, commits, pull requests,
  merging, and the required protection for `main`.

When adding a guide, add it to this index and to the task-specific reference
table in `AGENTS.md` if coding agents need to discover it.
